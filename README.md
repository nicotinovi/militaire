# Militaire — французский по делу

Тренажёр по всем 11 темам и 4 страницам `VOCABULAIRE MILITAIRE.pdf`: **188 карточек**. Работает без сервера и без сборки. Нет внешних шрифтов, библиотек, аналитики или учётных записей.

## Запуск на компьютере

Откройте `index.html` двойным щелчком в современном браузере. Все ресурсы лежат рядом. Не перемещайте только HTML отдельно от остальных файлов.

Прогресс сохраняется в браузере. Для более надёжного хранения и работы без интернета на телефоне используйте постоянный адрес GitHub Pages. При переходе с локального файла на опубликованный адрес перенесите прогресс через «Настройки → Скачать / Загрузить прогресс». В режиме инкогнито данные удаляются после закрытия браузера.

## Что умеет тренажёр

- Выбор перевода, ввод ответа и карточки с самооценкой.
- Перевод FR → RU, RU → FR и смешанное направление.
- Одна из 11 тем или весь словарь; 10, 20, 40 или все карточки.
- Новые и менее изученные слова получают приоритет.
- Последовательность тренировки восстанавливается после перезагрузки страницы.
- Ошибки хранятся отдельно по двум направлениям. Повторение ошибок использует ввод ответа.
- «Исправить сейчас» позволяет повторно ввести перевод. Исправление убирает ошибку из очереди, сохраняя первоначальный результат.
- «Мой ответ тоже верный» добавляет синоним в допустимые ответы и пересчитывает текущую попытку. Действие отмечается в истории.
- Словарь с поиском, вариантами перевода, редактированием и восстановлением исходной карточки.
- Статистика: первые ответы на задания, точность, уникальные карточки, серия дней, график за 7 дней, история последних 50 ответов. «Выучено» — три последних ответа верны и нет открытых ошибок. Самооценка карточек входит в статистику и явно отмечена как самооценка.
- Французские знаки на экранной клавиатуре, переключатель строгой проверки акцентов.
- Озвучивание через возможности браузера: нужен установленный французский голос. Некоторые голоса требуют интернет.
- Экспорт и импорт всей истории, ошибок, личного словаря и настроек в JSON.

Дни считаются по местному времени устройства. В исходной точности учитывается только первый ответ на каждое задание, а не попытки исправления. Если вы решаете ту же карточку в новой тренировке, это новая попытка.

## GitHub Pages: открыть на телефоне и компьютере

1. Войдите в [GitHub](https://github.com/) и создайте новый **публичный** репозиторий с именем `militaire`. Имена можно выбрать другие; они попадут в адрес сайта.
2. В репозитории выберите **Add file → Upload files**. Если репозиторий пустой, ссылка **uploading an existing file** ведёт к тому же действию.
3. Если вы используете готовый архив `militaire-github.zip`, сначала распакуйте его. Загрузите **содержимое этой папки**, а не папку целиком и не ZIP. На верхнем уровне репозитория должны быть `index.html`, `styles.css`, `data.js`, `core.js`, `app.js`, `sw.js`, `manifest.webmanifest`, `icon.svg`, `icon-192.png`, `icon-512.png`, `.nojekyll` и этот README. Папка `tests` нужна только для разработки и необязательна для публикации. PDF и ваши файлы прогресса загружать не требуется.
4. Нажмите **Commit changes**. Если нужный файл не попал в загрузку, добавьте его отдельно. `.nojekyll` можно создать через **Add file → Create new file**; достаточно пустого файла.
5. Откройте **Settings → Pages**. В блоке **Build and deployment** установите **Source: Deploy from a branch**. Затем **Branch: main**, папку **/ (root)** и нажмите **Save**. Если ваша ветка называется иначе, выберите её.
6. Дождитесь окончания публикации. Её состояние видно в **Actions**, а готовая ссылка появится в **Settings → Pages**. Обычно адрес имеет вид `https://ВАШ-ЛОГИН.github.io/militaire/`.
7. Откройте **эту ссылку** в браузере компьютера и телефона. Ссылка на сам репозиторий (`github.com/...`) — это страница файлов, для занятий нужен адрес `github.io`.

Источник: [официальная инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site), проверена 11 ноября 2026 года.

Если вместо тренажёра появляется 404, проверьте завершение публикации в Actions, регистр имени `index.html`, выбранную ветку и расположение `index.html` в корне. Все пути относительные, поэтому сайт работает и в подпапке репозитория.

## Значок на главном экране и работа без интернета

- **iPhone / iPad:** откройте опубликованный HTTPS-адрес в Safari, выберите «Поделиться → На экран Домой».
- **Android:** откройте сайт в браузере и в его меню найдите «Установить приложение» или «Добавить на главный экран». Название пункта зависит от браузера.
- После первого полного открытия и загрузки ресурсов сервис-воркер сохраняет приложение для офлайн-доступа. Дождитесь загрузки страницы, прежде чем выключать интернет. Возможность установки и хранения офлайн-данных зависит от браузера.
- Через `file://` сервис-воркер не запускается; там сайт работает за счёт файлов в папке.
- После изменения исходников увеличьте `VERSION` в `sw.js` (например, `militaire-v2`), загрузите изменённые файлы на GitHub и обновите страницу при наличии интернета.

## Перенос прогресса

Сайт работает отдельно в каждом браузере. GitHub Pages не предоставляет облачную синхронизацию.

1. На устройстве с актуальной статистикой: **Настройки → Скачать прогресс**.
2. Передайте полученный `militaire-progress-ДАТА.json` на второе устройство удобным способом.
3. На втором устройстве: **Настройки → Загрузить прогресс**, выберите файл, проверьте число ответов и подтвердите замену.

Импорт **заменяет**, а не объединяет историю. Перед заменой можно скачать текущую копию. Незавершённая очередь тренировки не переносится, но все уже записанные ответы переносятся. Регулярно сохраняйте копию: удаление данных сайта или браузера удаляет локальный прогресс. Одновременная работа в нескольких вкладках не поддерживается: при изменении в другой вкладке появится предупреждение, после которого нужно обновить страницу.

## Как подготовлен словарь

Варианты через `/` раскрыты в самостоятельные выражения. Мужские и женские формы прилагательных принимаются как эквивалентные ответы. Для синонимов сохранены дополнительные варианты. Артикли являются частью французского ответа.

Исправлены явные опечатки, склейки слов и надстрочные обозначения рода в исходнике. Для `égoïste` добавлен отсутствующий русский перевод. У `Respectez les ordres !` добавлен буквальный перевод и сохранён вариант из PDF. Содержательные уточнения отмечены в карточках. `La veille des exercices` намеренно присутствует в темах «Повседневная служба» и «Полезные связки», как в исходнике.

Это проверка по словарным вариантам: произвольный смысловой перевод не всегда будет принят автоматически. Подходящие варианты можно добавлять самостоятельно.

## Разработка и проверки

Нужен Node.js с поддержкой `node:test`. В папке тренажёра выполните:

```sh
node --test tests/core.test.cjs tests/app.test.cjs
```

Тесты проверяют нормализацию, оба направления, строгие акценты, исправление и перезачёт, независимость очередей ошибок, статистику, подбор вариантов, полный охват тем и валидацию импорта. Интерфейс проверяется отдельно в минимальной модели документа без браузера: основные страницы, ответы, исправления, редактирование, импорт, перезагрузка, конфликт вкладок и файлы офлайн-кеша. Это не проверка реальной отрисовки: её нужно выполнить в браузере. Сайт не требует npm или установки пакетов.

При локальной HTTP-разработке удобно использовать стандартный сервер Python:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

Затем открыть `http://127.0.0.1:8765/`. Прогресс локального файла, локального сервера и GitHub Pages хранится раздельно.
